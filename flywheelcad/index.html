FlywheelCAD

Python-first, constraint-driven CAD.

FlywheelCAD combines direct UI sketch editing with script-driven modeling in plain Python files. You can work interactively, then keep the model reproducible and reusable through script execution.

What You Can Do

Sketch and constrain

Create points, lines, circles, arcs, ellipses, and splines; then apply geometric and dimensional constraints with variables.

Model in 3D

Turn closed sketch regions into bodies using extrude/revolve, then combine results with boolean union, difference, and intersection.

Script everything

`.fwcad` files are plain Python and can import local helper modules in the same project folder.

Create custom planes

Build custom sketch planes from 3D topology points and continue feature creation in those local coordinate systems.

Script Model Quick Start

The scripting flow in FlyWheelCAD is based on plain Python files that call the flywheelcad API. A minimal file looks like this: 

from flywheelcad import *
cad = FlyWheelCAD()

cad.with_sketch("xy")
# create geometry, apply constraints, generate bodies

Use the included TestProjects as templates

  • test.fwcad: imports a helper module and places repeated geometry.
  • test_polygons.fwcad: regular, nested, and spoke polygon generators.
  • test_gears.fwcad: gear profiles, extrusion, and boolean subtraction.
  • test_showcase.fwcad: end-to-end example with custom plane creation.

Typical script progression

  1. Start a sketch context with cad.with_sketch("xy").
  2. Create geometry directly or import helpers from sibling .py modules.
  3. Build solid bodies with cad.extrude(...) or cad.revolve(...).
  4. Use booleans like cad.bool_difference(...) to form final parts.
  5. Create custom planes from body topology with cad.create_sketch_plane(...).

Example: helper import + 3D feature

from flywheelcad import *
from CADgears import gear_outline

cad = FlyWheelCAD()
gear = gear_outline(center_x=280, center_y=40, tooth_count=18, module=5.5, plane_name="xy")
gear_body = cad.extrude("xy", gear["profile"], gear["profile_inside"], 45, quality="ultra")

end_face = cad.create_sketch_plane(gear_body.v0, gear_body.v1, gear_body.v2, name="gear_end")
cad.with_sketch("gear_end")
cap = cad.circle2d(origin_gear_end, 18)
cap_body = cad.extrude("gear_end", [cap], (0, 0), 20, quality="high")
