FlywheelCAD

Python-first, constraint-driven CAD for reproducible sketch and body workflows.

Direct sketch editing in the UI, backed by a live Python script. Constrain geometry, build bodies with extrude, revolve, loft and booleans, compose reusable components into mated assemblies, and export bodies as mesh files for 3D printing in various formats (.3mf, .stl, .obj). The script stays the source of truth.

What You Can Do

Sketch and constrain

  • Points, lines, circles, arcs, ellipses, splines, trims.
  • Solve a sketch with geometric constraints, dimensions and shared variables.
  • Live badge: under-, fully- or over-constrained, and which constraints conflict.

Build bodies and analyze them

  • Extrude, revolve and loft closed regions into solids.
  • Edge rounding, wall taper (draft), plane-normal offset, twist for helical and herringbone shapes.
  • Booleans — union, subtract, intersect, with an optional smooth or chamfer blend at the seam.
  • Sections and projections derived from bodies.
  • Mesh export for 3D printing in various formats: .3mf, .stl, .obj.
  • Parametric: edit a body’s sketch and it re-derives; delete it and everything built on it cascades.
  • GPU meshing — whole boolean trees in one pass; set_cell_size pins an absolute resolution per body.

Work across multiple planes

  • Standard xy, yz and zx sketch planes.
  • Custom sketch planes from three points — picked off the topology of existing bodies, or defined directly as typed X/Y/Z coordinates.
  • Multi-section lofts sweep one smooth solid through any number of cross-sections — how the sample fuselages and wings are built.

Compose components into assemblies

  • Define a part once in with cad.component(...); export its bodies and named anchor points.
  • Place it repeatedly with cad.instance(...) — translated, mirrored, scaled, rotated.
  • Snap instances together with mates.
  • Parametric components (one wing factory, many wings), each in its own file, nesting into sub-assemblies.
  • Per-body colors and finishes (matte, glossy, metallic, glass) carry into .3mf and .obj export — the latter via a sibling .mtl. .stl is geometry only.

Place parts from component libraries

  • Component libraries are folders of parametric part modules.
  • A standard library ships in the app: NEMA steppers, hobby servos and horns, metric cap screws / nuts / washers, ball bearings, T-slot extrusion, RC linkage.
  • Add your own under ~/Documents/FlywheelCAD/Libraries/.
  • Component → Insert from Library… — live 3D preview and parameter fields.
  • Copy-on-use: the module is vendored into the document’s lib/, so a design stays self-contained and a library update never silently changes it. Update from Library refreshes on your terms.

Keep everything reproducible

  • The right panel holds the model as editable Python.
  • A document is a plain .py file or a .fwcad project bundle — a folder packaging the script with everything it imports.
  • Helper modules sit next to the main file (File → Add File to Project…).
  • Using an AI assistant? Drop in the AI scripting guide — the full API reference in one Markdown file.

Sample Assemblies

Six multi-file assemblies showing the component workflow end to end: parts in their own files, parametric factories, instances with mirrors and transforms, mates onto named anchor points, catalog parts from the standard library. Download the Sample Assemblies bundle and open the top-level file. Click a shot to enlarge.

Glider.fwcad/main.py

  • Multi-loft fuselage: nose cap, cockpit, tail boom.
  • Parametric NACA wing — non-linear taper, washout, dihedral; instanced per side, left mirrored.
  • Symmetric-airfoil T-tail, per-component colors.

ToyAirplane.fwcad/main.py

  • The introductory assembly: fuselage, parametric wing (right instanced, left mirrored), tail.
  • Each part its own component file, mated to mount points the fuselage exports.
  • Move a mount, the parts follow.

AirplaneNested.fwcad/main.py

  • Two-level nesting: leaf parts (fuselage, wing, engine, stabilizer) into sub-assemblies — a powered wing, an empennage.
  • Sub-assemblies re-export their children’s parts and anchors.
  • The top assembly mates them as opaque units.

FlyingWing.fwcad/main.py

  • Prandtl-D-style tailless wing: NACA 4412 center section, swept and tapered on a bell-spanload twist schedule — tips at negative incidence.
  • Pusher motor pod with spinner and prop.
  • Elevons cut as separate bodies: V-groove hinge opening from the upper skin, embedded servo, control horn and pushrod per side.
  • Heavy generated-from-math geometry throughout.

MotorMount.fwcad/main.py

  • Standard-library showcase: a plate whose every cutout is a declared region hole.
  • Catalog parts straight from the library — NEMA 17 stepper, servo with a horn mated to its output spline, four M3 cap screws, a 608 bearing in its seat.
  • Its vendored lib/standard/ travels with the sample.

AxialFluxMotor.fwcad/main.py

  • The largest sample: double-rotor, coreless-stator axial flux machine, roughly 400 mm across — 32 poles, 24 coils, three phase.
  • Every structural part prints flat; the rest of the bill of materials is off-the-shelf (block magnets, 6902 bearings, a 15 mm shaft), so the document doubles as a build guide.
  • A stress test of booleans and patterning — its notes recommend High or Ultra mesh quality before exporting for print.

Showcase Projects

Five short, heavily-commented projects, one concept each: sketching with constraints, body creation, lofting, components, the standard library. Read the comments top to bottom — they are meant to be learned from, not just run. Download the Showcase Projects bundle and open each folder’s .py file.

1 · Sketching, constraints & dimensions — 01_sketch_bracket.fwcad/main.py

  • A flat bracket drawn rough, then pinned with geometric constraints — horizontal, vertical, parallel, perpendicular, tangent fillet.
  • Dimensions bound to shared variables: change WIDTH, HEIGHT, HOLE_DIA or SLANT and the part re-solves.
  • A light extrude makes the profile read in 3D.

2 · Body creation: extrude + revolve + booleans — 02_knob.fwcad/main.py

  • A hand-knob from both body operations: revolved dished body, extruded boss unioned on.
  • A ring of cylinders unioned, then differenced to scallop the rim into finger grips; a subtracted shaft bore.
  • Shows edge_radius, offset, boolean union / difference.

3 · Custom planes & multi-level loft — 03_loft_duct.fwcad/main.py

  • A transition fairing: near-round inlet to wide, flat outlet.
  • Custom sketch planes stacked along the axis, each with a reusable oval section (profiles.oval(...)).
  • cad.multi_loft(...) through all four sections, no internal seams.

4 · Components: fixed + parametric — 04_standoff_kit.fwcad/main.py

  • A base plate with four hex standoffs — both ways to define reusable parts, side by side.
  • Fixed component: one specific part, exporting named anchors.
  • Parametric factory: any size on demand, memoised per size.
  • Instances mated by their base anchor onto the plate’s anchors.

5 · Library insertion & mating — 05_bearing_block.fwcad/main.py

  • A pillow bearing block: a 608 bearing pressed into the bore, four cap screws holding it down.
  • Catalog parts (bearing, cap_screw) from the standard component library, mated onto the block’s anchors.
  • Its vendored lib/standard/ travels with the sample.

Script Quick Start

A FlywheelCAD file is ordinary Python: import the API, create a FlywheelCAD object, enter a sketch context, emit geometry and body operations. 

from flywheelcad import *
cad = FlywheelCAD()

cad.with_sketch("xy")
p1 = cad.point2d(-60, -12.5)
p2 = cad.point2d(-20, -12.5)
line = cad.line2d(p1, p2)
cad.horizontal(line)
cad.length(line, 40)

Reusable logic goes in helper files next to the main script — the gear examples use exactly that pattern. 

from flywheelcad import *
from CADgears import gear_outline

cad = FlywheelCAD()
gear = gear_outline(center_x=0, center_y=0, tooth_count=24, module=5.0, plane_name="xy")
body = cad.extrude("xy", gear["region_ring"], 24, quality="high")

Bring Your Own AI

No AI integration — no cloud connection, no account, nothing leaves your machine. It doesn’t need one: every document is ordinary Python, so any coding agent you already use can write and refactor your models.

The AI Scripting Guide is the whole scripting surface in one Markdown file sized for an assistant’s context window:

  • Agent rules, full command reference, worked patterns.
  • Drop it into a session, describe the part, and let the agent do the hard geometry: involute gear teeth as circular arcs, accurate NACA airfoil sections, parametric part families.
  • The meshing gear pairs and the NACA glider wing are exactly that — ordinary Python emitting FlywheelCAD commands.

Whatever the agent writes stays a plain .py file: open it, run it, keep editing by hand or by prompt. The script stays the reproducible source of truth.
